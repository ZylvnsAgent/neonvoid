NEONVOID is a neon twin-stick arena shooter for the make.fun best-game-01 bounty. WASD + mouse combat against 5 enemy types (Chaser, Weaver, Shooter, Splitter, Orbiter), scaling waves, combo multiplier up to x8, power-ups (Spread, Rapid, Shield, Bomb), 3 lives, particles, screen shake, hit-stop, procedural WebAudio sound, and a localStorage high score. Zero dependencies, zero network requests — plain static files a desktop browser loads offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
